# 🗂️ File Sorter

**Сортируй файлы в один клик!**

Этот скрипт на Python раскладывает файлы из папки **Загрузки** (`C:/Users/user/Downloads`) по категориям в специальные папки на вашем компьютере. Данная программа будет развиваться становиться универсальной и удобной. 

---

## 🚀 Что сортирует скрипт?

| Тип файлов | Расширения | Куда сохраняет |
|------------|------------|----------------|
| 🖼️ **Изображения** | `.jpg`, `.jpeg`, `.png`, `.webp` | `C:/Users/user/Pictures/Рабочие Фото/Разобрать по папкам` |
| 💻 **Код и данные** | `.py`, `.json` | `C:/Users/user/Documents/Файлы програмирования` |
| ⚙️ **Программы** | `.exe` | `C:/Users/user/Documents/.exe` |
| 🎬 **Видео** | `.mp4`, `.mkv`, `.mov` | `C:/Users/user/Videos/Разобрать по папкам` |
| 📦 **Архивы** | `.zip` | `C:/Users/user/Documents/.zip` |

Если нужной папки не существует, скрипт создаст её автоматически (`os.makedirs`).

---

## 📥 Установка и настройка

1. **Скачай код:**
   ```bash
   git clone https://github.com/CukaNight/File-Sorter.git
   cd File-Sorter
   ```

2. **Убедись, что у тебя установлен Python 3.6+.**

3. **Важно!** Скрипт использует только встроенные библиотеки (`os`, `shutil`), поэтому ничего дополнительно устанавливать не нужно.

---

## ⚡ Как использовать (из командной строки)

Открой терминал (cmd) и выполни:
```bash
python \путь_к_папке_с_проектом\sort.py
```

**Пример:**
```bash
python C:\Users\user\Documents\File_Sorter\sort.py
```

После запуска все файлы из папки `Загрузки` будут автоматически разложены по соответствующим папкам.

---

## 🚀 Как использовать (Самый удобный способ)

Чтобы запускать сортировку прямо из папки **Загрузки**, создай `.bat` файл:

1. Открой Блокнот.
2. Вставь туда этот текст (замени `"C:\путь\к\папке\File-Sorter\sort.py"` на реальный путь к твоему скрипту):
   ```batch
   @echo off
   python "C:\Users\user\Documents\File_Sorter\sort.py"
   ```
3. Сохрани файл как `Сортировать_Загрузки.bat`. **Важно:** В поле «Тип файла» выбери «Все файлы».
4. Скопируй этот `.bat` файл в свою папку **Загрузки**.
5. **Всё!** Теперь, когда там накопился беспорядок, дважды кликни на `.bat` файл — и всё само рассортируется по папкам!

## 🔧 Как добавить новые форматы

1. Открой файл `sort.py`.
2. Найди функцию, которая отвечает за нужную категорию (например, `sort()` для изображений).
3. Внутри неё ты увидишь блоки с `ext = ".jpg"`. Скопируй такой блок и добавь своё расширение.

**Например, чтобы добавить сортировку `.gif`:**
```python
ext_gif = ".gif"
photo = [
    os.path.join(folder, f)
    for f in os.listdir(folder)
    if os.path.isfile(os.path.join(folder, f)) and f.lower().endswith(ext_gif.lower())
]
for file_path_gif in photo:
    photoname_gif = os.path.basename(file_path_gif)
    dst_path = os.path.join(dst_folder, photoname_gif)
    shutil.move(file_path_gif, dst_path)
```

4. Сохрани изменения и запусти скрипт снова.
