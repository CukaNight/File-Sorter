# 🗂️ File Sorter

**Сортируй файлы в один клик!**

Скрипт на Python раскладывает файлы из папки **Загрузки** по категориям в специальные папки на вашем компьютере. Программа использует словарь правил, что делает её гибкой и лёгкой в расширении.

---

## 🚀 Что сортирует скрипт (v2.0)

| Тип файлов | Расширения | Куда сохраняет |
|------------|------------|----------------|
| 🖼️ **Изображения** | `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` | `C:/Users/user/Pictures/Фото` |
| 🎬 **Видео** | `.mp4`, `.mov`, `.mkv`, `.avi` | `C:/Users/user/Videos/Видео` |
| 💻 **Код и данные** | `.py`, `.json`, `.csv`, `.xml` | `C:/Users/user/Documents/Код и данные` |
| ⚙️ **Программы** | `.exe`, `.msi` | `C:/Users/user/Documents/Программы` |
| 📦 **Архивы** | `.zip`, `.rar`, `.7z`, `.tar.gz` | `C:/Users/user/Documents/Архивы` |
| 🎵 **Аудио** | `.mp3`, `.wav`, `.flac` | `C:/Users/user/Music/Аудио` |
| 📄 **Документы** | `.pdf`, `.docx`, `.txt`, `.xlsx`, `.pptx` | `C:/Users/user/Documents/Документы` |

## 📥 Установка и настройка

1. **Скачай код:**
   ```bash
   git clone https://github.com/CukaNight/File-Sorter.git
   cd File-Sorter
   ```

2. **Убедись, что установлен Python 3.6+.**

3. Скрипт использует только встроенные библиотеки (`os`, `shutil`), ничего дополнительно устанавливать не нужно.

---

## ⚡ Как использовать (из командной строки)

```bash
python sort.py
```

После запуска все файлы из папки `Загрузки` будут автоматически разложены по соответствующим папкам.

---

## 🚀 Как использовать (самый удобный способ)

Чтобы запускать сортировку прямо из папки **Загрузки**, создай `.bat` файл:

1. Открой Блокнот.
2. Вставь:
   ```batch
   @echo off
   python "C:\Users\user\Documents\File_Sorter\sort.py"
   ```
   (Замени путь на реальный путь к твоему `sort.py`)

3. Сохрани как `Сортировать_Загрузки.bat` (в поле «Тип файла» выбери «Все файлы»).

4. Скопируй `.bat` файл в папку **Загрузки**.

5. Дважды кликни — и порядок наведён!

---

## 🛠️ Как добавить новый формат (v2.0)

Теперь это делается в одну строку:

1. Открой `sort.py`
2. Найди словарь `RULES`
3. Добавь новое расширение в нужную категорию:

```python
"Изображения": {
    "dest": "C:/Users/user/Pictures/Фото",
    "extensions": [".jpeg", ".jpg", ".png", ".webp", ".gif", ".bmp"]  # Добавлен .bmp
},
```

4. Сохрани и запусти скрипт.

---

## 🧠 Как это работает (для разработчиков)

Код построен на трёх элементах:

| Элемент | Что делает |
|---------|------------|
| `RULES` | Словарь с категориями, путями и расширениями |
| `move_by_extension()` | Универсальная функция перемещения файлов |
| `run()` | Проходит по словарю и вызывает функцию для каждой категории |
